## Security

Please report any security issue to [security@salesforce.com](mailto:security@salesforce.com)
as soon as it is discovered. This library limits its runtime dependencies in
order to reduce the total cost of ownership as much as can be, but all consumers
should remain vigilant and have their security stakeholders review all third-party
products (3PP) like this one and their dependencies.

Before this server is used beyond a personal development org, submit it for the
Salesforce MCP review process and add the approved build to the internal MCP
registry. A public GitHub copy is not an approval to connect it to Salesforce
data. The published Git history also needs the previously exposed credential
removed; deleting it from the current files does not remove it from old commits.
